Access haladó - Levéltári adatbázisok

Fejezet 8 Excel-Access integráció

Az Excel és Access gyakran együtt használhatók. Az Access tárolja és kezeli az adatokat (relációs adatbázis), az Excel pedig elemzi és visualizálja őket (táblázatok, grafikonok).

8.1 Mikor használjunk Excel-t, mikor Access-t?

8.1.1 Excel erősségei

  • Gyors adatbevitel: Könnyű táblázatban gépelni
  • Rugalmas: Szabad struktúra, összevont cellák, formázás
  • Vizualizáció: Grafikonok, diagramok, színek
  • Számítások: Képletek, függvények (SZUM, HA, FKERES)
  • Pivot táblák: Gyors összesítések

8.1.2 Access erősségei

  • Nagy adatmennyiség: Több millió rekord kezelése
  • Relációs kapcsolatok: Többtáblás struktúra (fondok → állagok → iratok)
  • Adatintegritás: Referenciális integritás, validáció
  • Lekérdezések: SQL, komplex szűrések, JOIN-ok
  • Többfelhasználós: Hálózaton megosztható

8.1.3 Az ideális munkafolyamat 🔄

1. EXCEL: Adatgyűjtés
   ↓
2. ACCESS: Import, normalizálás, kapcsolatok
   ↓
3. ACCESS: Lekérdezések, szűrések, összesítések
   ↓
4. EXCEL: Export, grafikonok, prezentáció

Példa levéltári munkafolyamat: 1. Terepen Excel-ben rögzíted az iratokat (gyors gépelés) 2. Access-be importálod (tiszta struktúra) 3. Access lekérdezésekkel keresed, szűröd (SQL) 4. Excel-be exportálod az eredményt (vezetőségi jelentés grafikonokkal)

8.5 Adattípus-problémák kezelése

8.5.1 Probléma 1: Dátum nem importálódik

Tünet: Access-ben #HIBA! vagy üres cella a dátum oszlopban

Ok: Excel különböző dátum formátumokat használ

Excel-ben lehet: - 2024.01.15 (magyar) - 01/15/2024 (amerikai) - 15-Jan-2024 (angol) - 45678 (soros szám!)

Megoldás Excel-ben (IMPORT ELŐTT):

1. Excel: Jelöld ki a dátum oszlopot
2. JOBB egérgomb → Cellák formázása
3. Szám fül → Kategória: Dátum
4. Típus: 2024.03.16 (vagy bármelyik egyértelmű formátum)
5. OK
6. Ellenőrizd: Minden cella dátumként jelenik meg?
7. Mentés
8. MOST importáld Access-be!

Megoldás Access-ben (IMPORT UTÁN):

Ha már importáltad és hibás:

-- Új mező létrehozása helyes dátummal:
ALTER TABLE tbl_IratokImport ADD COLUMN DátumJavított Date;

UPDATE tbl_IratokImport
SET DátumJavított = CDate([RosszDátum])
WHERE IsDate([RosszDátum]) = True;

-- Aztán töröld a rossz oszlopot, nevezd át a jót!

8.5.2 Probléma 2: Szám szövegként importálódik

Tünet: Számokat nem lehet összegezni, átlagolni

Ok: Excel-ben előtte aposztróf van: '123

Megoldás Excel-ben:

1. Jelöld ki a szám oszlopot
2. JOBB egérgomb → Cellák formázása
3. Kategória: Szám
4. Tizedesjegyek: 0 (ha egész szám)
5. OK
6. Ha még mindig zöld háromszög van → Kattints rá → "Számmá alakítás"

Megoldás Access-ben:

-- Frissítési lekérdezés:
UPDATE tbl_IratokImport
SET SzámMező = Val([SzámMező]);
-- Val() függvény: szövegből számot csinál

8.5.3 Probléma 3: NULL értékek (üres cellák)

Tünet: Import közben hiba: “Kötelező mező nem tartalmazhat NULL értéket”

Ok: Az Access táblában a mező “Kötelező: Igen”, de Excel-ben üres cellák vannak!

1. Excel: Oszlop kijelölése
2. Ctrl+F → Keresés: (hagyj üresen!)
3. Keresés helye: Értékek
4. Összes keresése
5. Látod az üres cellákat → töltsd ki őket!

Megoldás 2: Access mező módosítása

1. Táblatervezés
2. Mező kijelölése
3. Kötelező: Igen → Nem
4. Alapértelmezett érték: "Ismeretlen" (vagy bármi)
