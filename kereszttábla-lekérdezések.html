Fejezet 4 Kereszttábla lekérdezések

A kereszttábla lekérdezés (crosstab query) adatokat kétdimenziós táblázatos formába rendez, ahol a sorok és oszlopok egyaránt kategóriák, az értékek pedig összesítések.

Időigény: 15-20 perc
Hasznosság: Nagyon hasznos statisztikákhoz, jelentésekhez, Excel pivot táblákhoz!

4.1 Mi a kereszttábla?

A kereszttábla olyan lekérdezés, amely az adatokat mátrix formában jeleníti meg.

4.1.1 Hagyományos lekérdezés vs. Kereszttábla

Hagyományos csoportosítás (GROUP BY):

┌─────────────┬──────────────┬─────────────┐
│ ÁllagNév    │ Digitalizálva│ IratokSzáma │
├─────────────┼──────────────┼─────────────┤
│ Tanács      │ Igen         │     15      │
│ Tanács      │ Nem          │      8      │
│ Színház     │ Igen         │     12      │
│ Színház     │ Nem          │      5      │
│ Népszámlálás│ Igen         │     20      │
│ Népszámlálás│ Nem          │      0      │
└─────────────┴──────────────┴─────────────┘

6 sor, 3 oszlop

Ugyanez kereszttáblaként:

┌─────────────┬──────┬──────┬──────────┐
│ ÁllagNév    │ Igen │  Nem │ Összesen │
├─────────────┼──────┼──────┼──────────┤
│ Tanács      │  15  │   8  │    23    │
│ Színház     │  12  │   5  │    17    │
│ Népszámlálás│  20  │   0  │    20    │
└─────────────┴──────┴──────┴──────────┘

3 sor, 4 oszlop

Előnyök: - Tömörebb: 3 sor a 6 helyett - Áttekinthetőbb: Egy pillantással látható a különbség - Excel-kompatibilis: Pivot táblákhoz hasonló - Könnyen exportálható: Jelentésekhez, grafikonokhoz

4.1.2 Kereszttábla elemei

Anatómia:

                    OSZLOPFEJLÉCEK
                    ↓     ↓     ↓
┌─────────────┬──────┬──────┬──────────┐
│ SORFEJLÉC   │ Igen │  Nem │ Összesen │ ← Összesítő oszlop (opcionális)
├─────────────┼──────┼──────┼──────────┤
│ Tanács      │  15  │   8  │    23    │
│ Színház     │  12  │   5  │    17    │ ← ÉRTÉKEK (Count, Sum, Avg, stb.)
│ Népszámlálás│  20  │   0  │    20    │
└─────────────┴──────┴──────┴──────────┘

Komponensek: 1. Sorfejlécek (Row Headings): Baloldali kategóriák (ÁllagNév) 2. Oszlopfejlécek (Column Headings): Felső kategóriák (Igen/Nem) 3. Értékek (Values): Összesítések (Count, Sum, stb.) 4. Összesítő oszlop (opcionális): Soronkénti összeg

4.2 Kereszttábla varázsló részletesen

A legegyszerűbb módszer a Kereszttábla varázsló használata.

⏱️ Időigény: 5 perc

4.2.1 1. LÉPÉS: Varázsló indítása

1. Létrehozás fül (felső menüszalag)
2. Lekérdezésvarázsló gomb (Lekérdezések csoport)

Felugró ablak: “Új lekérdezés”

│ Új lekérdezés                      │
├────────────────────────────────────┤
│ ○ Egyszerű lekérdezésvarázsló      │

│ ○ Ismétlődő rekordok keres...     │
│ ○ Ismétlődés nélküli rekordok...  │
│                                    │
│     [OK]       [Mégse]             │
└────────────────────────────────────┘

3. Kereszttábla lekérdezésvarázsló → Kijelöld
4. OK gomb

4.2.2 2. LÉPÉS: Forrás tábla kiválasztása

Képernyő: “Milyen táblához vagy lekérdezéshez tartalmazza a kereszttábla lekérdezés mezőit?”

┌────────────────────────────────────┐
│ Nézet:                             │
│ ● Táblák  ○ Lekérdezések  ○ Mindkettő │
├────────────────────────────────────┤
│ Elérhető táblák:                   │
│ ┌────────────────────────────────┐ │
│ │ tbl_Fondok                     │ │
│ │ tbl_Állagok                    │ │
│ │ tbl_Iratok        ← Válaszd!   │ │
│ │ tbl_Kikérések                  │ │
│ └────────────────────────────────┘ │
│                                    │
│  [<Vissza]  [Tovább>]  [Mégse]    │
└────────────────────────────────────┘

5. tbl_Iratok → Kattints rá (kijelölöd)
6. Tovább > gomb

Tipp: Ha több táblát szeretnél összekombinálni (pl. tbl_Állagok + tbl_Iratok), először készíts egy szelekciós lekérdezést JOIN-nal, aztán arra építsd a kereszttáblát!

4.2.5 5. LÉPÉS: Értékek beállítása

Képernyő: “Milyen számot szeretne kiszámolni minden egyes oszlop- és sorcímke-metszésponthoz?”

Mit jelent ez? Mi legyen a cellákban: összeg, darabszám, átlag, stb.?

┌────────────────────────────────────┐
│ Mezők:               Függvények:   │
│ ┌──────────────┐  ┌────────────┐   │
│ │ IratID       │  │ Összeg     │   │
│ │ IratCím      │  │ Átlag      │   │
│ │ Jelzet       │  │ Min        │   │
│ │ DoboztárSzám │  │ Max        │   │
│ └──────────────┘  │ Darabszám  │ ← │
│                   │ StdDev     │   │
│                   │ Var        │   │
│                   └────────────┘   │
│                                    │
│ ☑ Igen, szerepeljen a sor összege  │ ← Összesítő oszlop
│                                    │
│ Mintaelőnézet:                     │
│ ┌──────────┬──────┬──────┬──────┐  │
│ │ ÁllagID  │ Igen │  Nem │Összeg│  │
│ ├──────────┼──────┼──────┼──────┤  │
│ │    1     │  15  │   8  │  23  │  │
│ └──────────┴──────┴──────┴──────┘  │
│                                    │
│  [<Vissza]  [Tovább>]  [Mégse]    │
└────────────────────────────────────┘

11. Mezők lista: IratID → Kattints rá
12. Függvények lista: Darabszám → Kattints rá
13. ☑ "Igen, szerepeljen a sor összege" → Pipáld be!
14. Tovább > gomb

Függvények magyarázata:

Függvény Magyar Mire jó?
Sum Összeg Számok összeadása (pl. iratok száma ÖSSZESEN)
Avg Átlag Átlagérték (pl. átlagos oldalszám)
Min Minimum Legkisebb érték
Max Maximum Legnagyobb érték
Count Darabszám Rekordok számolása ← LEGGYAKORIBB!
StdDev Szórás Statisztikai szórás
Var Variancia Statisztikai variancia

Mikor melyiket használd? - Rekordok számolása → Count (Darabszám) ✅ Legtöbbször ezt! - Számok összegzése → Sum (pl. kikért iratok száma összesen) - Átlagolás → Avg (pl. átlagos látogatási idő)

4.3 SQL szerkesztése és magyarázat

A varázsló alapvető SQL-t generál, de mi finomítani akarjuk!

4.3.1 Generált SQL (varázsló eredménye):

Tervezés fül → Nézet → SQL nézet

SQL kód:

TRANSFORM Count(tbl_Iratok.IratID) AS [IratID - Darabszám]
SELECT tbl_Iratok.ÁllagID
FROM tbl_Iratok
GROUP BY tbl_Iratok.ÁllagID
PIVOT tbl_Iratok.Digitalizálva;

Probléma: - Az ÁllagID szám (1, 2, 3…), nem beszédes! - Nincs állag név, nem tudjuk, melyik állagról van szó!

4.3.2 Javított SQL (JOIN-nal, állag névvel):

Töröld ki az egész SQL-t, és írd be ezt:

TRANSFORM Count(tbl_Iratok.IratID) AS IratDarab
SELECT tbl_Állagok.ÁllagNév, 
       Count(tbl_Iratok.IratID) AS [Összesen]
FROM tbl_Állagok 
INNER JOIN tbl_Iratok ON tbl_Állagok.ÁllagID = tbl_Iratok.ÁllagID
GROUP BY tbl_Állagok.ÁllagNév
PIVOT tbl_Iratok.Digitalizálva;

VAGY F5

Eredmény:

├───────────────────────────┼─────┼─────┼──────────┤

4.3.3 TRANSFORM…PIVOT SQL magyarázat

A kereszttábla lekérdezés SQL-je speciális szintaxist használ.

Általános felépítés:

TRANSFORM <összesítő függvény>
SELECT <sorfejlécek>, <összesítő oszlop (opcionális)>
FROM <tábla(k)>
WHERE <feltétel (opcionális)>
GROUP BY <sorfejlécek>
PIVOT <oszlopfejlécek>;

Részletes magyarázat:

4.3.3.1 1. TRANSFORM sor

TRANSFORM Count(tbl_Iratok.IratID) AS IratDarab

Mit csinál: - TRANSFORM = “alakítsd át” (kereszttáblává) - Count(tbl_Iratok.IratID) = számold az IratID-kat (rekordokat) - AS IratDarab = eredmény neve (opcionális)

Ez adja az értékeket a cellákban!

4.3.3.2 2. SELECT sor

SELECT tbl_Állagok.ÁllagNév, 
       Count(tbl_Iratok.IratID) AS [Összesen]

Mit csinál: - tbl_Állagok.ÁllagNév = sorfejlécek (bal oldali kategóriák) - Count(tbl_Iratok.IratID) AS [Összesen] = összesítő oszlop (opcionális)

Ez adja a sorokat és az összesítő oszlopot!

4.3.3.3 3. FROM + JOIN

FROM tbl_Állagok 
INNER JOIN tbl_Iratok ON tbl_Állagok.ÁllagID = tbl_Iratok.ÁllagID

Mit csinál: - Összeköti a két táblát az ÁllagID alapján - INNER JOIN = csak olyan állagok, amelyekhez VAN irat

4.3.3.4 4. GROUP BY sor

GROUP BY tbl_Állagok.ÁllagNév

Mit csinál: - Csoportosít állag név szerint - Minden egyedi ÁllagNév = egy sor a kereszttáblában

4.3.3.5 5. PIVOT sor

PIVOT tbl_Iratok.Digitalizálva;

Mit csinál: - PIVOT = “fordítsd el” (sorokból oszlopokat csinál) - tbl_Iratok.Digitalizálva = a mező, amelynek értékeiből oszlopok lesznek - Értékek: Igen és Nem → két oszlop

Ez adja az oszlopfejléceket!

4.3.4 Vizualizáció - Mi történik?

Normál lekérdezés (GROUP BY):

SELECT ÁllagNév, Digitalizálva, COUNT(*) AS Darab
FROM ...
GROUP BY ÁllagNév, Digitalizálva

┌───────────────┬──────────────┬──────┐
│ ÁllagNév      │ Digitalizálva│ Darab│
├───────────────┼──────────────┼──────┤
│ Tanács        │ Igen         │  15  │ ← 1. sor
│ Tanács        │ Nem          │   8  │ ← 2. sor
│ Színház       │ Igen         │  12  │ ← 3. sor
│ Színház       │ Nem          │   5  │ ← 4. sor
└───────────────┴──────────────┴──────┘

Kereszttábla (PIVOT):

PIVOT Digitalizálva → Igen és Nem oszlopok lesznek!

┌───────────────┬──────┬──────┐
│ ÁllagNév      │ Igen │  Nem │
├───────────────┼──────┼──────┤
│ Tanács        │  15  │   8  │ ← 1+2. sor összevonva!
│ Színház       │  12  │   5  │ ← 3+4. sor összevonva!
└───────────────┴──────┴──────┘

4.4 Kereszttábla dátumokkal

A kereszttábla nagyon hasznos dátumokkal - havi/éves statisztikák készítéséhez!

4.4.1 Példa 1: Digitalizálás havi bontásban

Feladat: Hány iratot digitalizáltunk havonta 2024-ben?

SQL:

TRANSFORM Count(tbl_Iratok.IratID) AS Darab
SELECT Format([DigitalizálásDátuma],"yyyy") AS Év
FROM tbl_Iratok
WHERE Digitalizálva = True
GROUP BY Format([DigitalizálásDátuma],"yyyy")
PIVOT Format([DigitalizálásDátuma],"mmmm");

Magyarázat:

  • TRANSFORM: Számláld az iratokat
  • SELECT: Év (2024)
  • GROUP BY: Év szerint csoportosít
  • PIVOT: Format(..., "mmmm") = hónap neve (január, február, …)
  • WHERE: Csak digitalizált iratok

Eredmény:

┌─────┬─────────┬─────────┬────────┬────────┬─────┬─────────┬──────────┐
│ Év  │ január  │ február │ március│ április│ ... │ november│ december │
├─────┼─────────┼─────────┼────────┼────────┼─────┼─────────┼──────────┤
│ 2024│    15   │    8    │   12   │   18   │ ... │    22   │    10    │
└─────┴─────────┴─────────┴────────┴────────┴─────┴─────────┴──────────┘

Formátum Eredmény Példa

"mm" Hónap száma 03 (március)
"mmmm" Hónap neve március
"mmm" Hónap rövid már.
"q" Negyedév 1 (Q1)
"ww" Hét száma 12

4.6 Hibaelhárítás

4.6.1 H1: “Túl sok oszlop”

Probléma: A PIVOT mező túl sok egyedi értéket tartalmaz.

Példa:

PIVOT tbl_Iratok.IratCím;  -- HIBA! Minden iratcím = 1 oszlop!
-- 500 különböző iratcím → 500 oszlop!

Megoldás: Használj kategorizált mezőt (pl. Igen/Nem, hónap, negyedév)!

-- HELYES:
PIVOT Format([DigitalizálásDátuma],"mmmm");  -- Max. 12 oszlop (hónapok)

4.6.2 H2: “NULL értékek az oszlopokban”

Probléma: Üres cellák a kereszttáblában.

Példa:

┌───────────────┬──────┬──────┐
│ ÁllagNév      │ Igen │  Nem │
├───────────────┼──────┼──────┤
│ Tanács        │  15  │      │ ← Üres! (NULL)
└───────────────┴──────┴──────┘

Ok: Nincs olyan rekord, ahol Tanács + Digitalizálva = Nem

Megoldás: Használj Nz() függvényt (Null-ból zéró):

TRANSFORM Nz(Count(tbl_Iratok.IratID), 0) AS Darab

Eredmény:

┌───────────────┬──────┬──────┐
│ ÁllagNév      │ Igen │  Nem │
├───────────────┼──────┼──────┤
│ Tanács        │  15  │   0  │ ← Mostmár 0! 
└───────────────┴──────┴──────┘

4.6.3 H3: “Hónapok rossz sorrendben”

Probléma: Alfabetikus sorrend (április, augusztus, …)

Ok: A hónap szöveg, nem szám!

Megoldás: Használj hónap számot csoportosításhoz, nevet csak PIVOT-ban:

TRANSFORM Count(*) AS Darab
SELECT Format([Dátum],"yyyy") AS Év,
       Month([Dátum]) AS HónapSzám  ← Csoportosításhoz
FROM ...
GROUP BY Format([Dátum],"yyyy"), Month([Dátum])
PIVOT Format([Dátum],"mmmm");  ← Csak megjelenítéshez

-- Majd rendezd HónapSzám szerint!

Exercise 4.2 2. gyakorlat: Doboztár prefix × Állag kereszttábla

Feladat: Készíts kereszttáblát, amely megmutatja, állag-onként hány irat van melyik doboztár típusban (TB, TANK, SZ, K, stb.)!

TRANSFORM Count(tbl_Iratok.IratID) AS Darab

INNER JOIN tbl_Iratok ON tbl_Állagok.ÁllagID = tbl_Iratok.ÁllagID
GROUP BY tbl_Állagok.ÁllagNév
PIVOT Left([DoboztárSzám],InStr([DoboztárSzám],"-")-1);
