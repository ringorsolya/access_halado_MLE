Fejezet 6 Alapszintű makrók

A makrók automatizálják az ismétlődő feladatokat. Egyetlen gomb megnyomásával futtathatunk lekérdezéseket, nyithatunk űrlapokat, exportálhatunk jelentéseket, és még sok mást!

6.1 Mi a makró?

A makró parancsok sorozata, amelyet az Access végrehajt egy művelet hatására (pl. gombnyomás).

Analógia: Mint egy recept - lépésről-lépésre utasítások.

Példa: “Gombnyomásra nyisd meg a frm_Iratok űrlapot szerkesztési módban!”

6.1.1 Makró vs. VBA

Jellemző Makró VBA (Visual Basic)
Nehézség Könnyű Nehéz (programozás)
Felület Vizuális, legördülők Kód írása
Használat Egyszerű feladatok Bonyolult logika
Példák Űrlap megnyitása, exportálás Ciklusok, feltételek, API hívások

Most a makrókat tanuljuk - nincs kódolás, csak kattintgatás!

Mikor használj makrót? - Gyakran ismétlődő feladat (pl. napi jelentés exportálás) - Gomb az űrlapon (pl. “Nyomtatás” gomb) - Egyszerű automatizálás (nyitás, zárás, szűrés)

Mikor NEM elég a makró? - Bonyolult logika (ha-akkor-egyébként többször egymásba ágyazva) - Ciklusok (végigmenni 1000 rekordon és mindegyikkel valami) - Külső alkalmazások vezérlése (Word, Excel, Outlook) - Adatbázis-műveletek (rekordok törlése, módosítása feltételek alapján)

Időigény: 5 perc
Cél: Készítsünk egy gombot, amely megnyit egy űrlapot!

6.2.3 3. LÉPÉS: Paraméterek beállítása

Csak a fontosakat kell kitölteni!

6. Űrlap neve: [▼] → Kattints a legördülőre
   → Lista: frm_Fondok, frm_Állagok, frm_Iratok
   → Válaszd: frm_Iratok

7. Nézet: [▼ Űrlap nézet] ← Maradhat! 
   (Űrlap nézet = normál szerkesztési nézet)

8. Adatmód: [▼ Szerkesztés] ← Maradhat! 
   (Szerkesztés = lehet módosítani a rekordokat)

9. Többi mező: HAGYD ÜRESEN!

Paraméterek magyarázata:

Paraméter Mit csinál? Mikor módosítsd?
Űrlap neve Melyik űrlapot nyitja meg MINDIG kitöltendő!
Nézet Milyen nézetben (Űrlap, Adatlap, Tervezés) Általában “Űrlap nézet”
Szűrőnév Előre mentett szűrő neve Ha van mentett szűrő
Feltétel SQL WHERE feltétel Speciális szűréshez
Adatmód Szerkesztés / Hozzáadás / Csak olvasás Ha írásvédett legyen
Ablak mód Normál / Rejtett / Ikon / Párbeszéd Speciális megjelenítéshez

6.2.4 4. LÉPÉS: Makró mentése

10. Ctrl+S (vagy Fájl → Mentés)

Felugró ablak: “Mentés másként”

13. Jobb egérgomb a "mcr_IratokMegnyitás" fülre → Bezárás

6.3 Makró lekérdezés futtatásához

⏱️ Időigény: 5 perc

Cél: Készítsünk gombot, amely futtat egy lekérdezést!

6.3.1 Makró létrehozása

1. Létrehozás → Makró

2. Új művelet: Kezd el gépelni "Lekér"
   → LekérdezésMegnyitása

3. Paraméterek:
   - Lekérdezés neve: qry_DigitalizáltIratok
   - Nézet: Adatlap nézet
   - Adatmód: Szerkesztés

4. Ctrl+S → Név: mcr_DigitalizáltLekérdezés
5. Bezárás

6.3.2 Gomb hozzáadása (gyorsított)

1. frm_Fondok Tervezési nézet
2. Gomb vezérlő → Kattints az űrlapra
3. Varázsló:
   - Kategória: Egyéni
   - Művelet: Egy makró futtatása
   - Makró: mcr_DigitalizáltLekérdezés
   - Szöveg: "Digitalizált iratok"
   - Gomb neve: cmd_DigitalizáltLekérdezés
4. Befejezés
5. Teszt (F5) → Kattints a gombra → Lekérdezés megnyílik!

6.4 Makró exportáláshoz

Időigény: 10 perc
Hasznosság: NAGYON hasznos napi jelentésekhez!

Cél: Automatizáljuk egy jelentés PDF-be exportálását egy gombnyomással!

6.4.1 Makró létrehozása

1. Létrehozás → Makró

2. Új művelet: Kezd el gépelni "Kiír"
   → KiírásObjectMásolat

Paraméterek kitöltése:

3. Objektumtípus: [▼] → Jelentés

4. Objektum neve: [▼] → rpt_FondStatisztika
   (válaszd ki a jelentésed nevét)
